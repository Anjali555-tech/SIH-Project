# Project Name

## What It Does
Using Natural Language Processing (NLP) and AI to analyze text and identify early warning signs of self-harm (SIF precursors). SIH Project.

## Why I Built It
Built for the Smart India Hackathon to address the critical need for early detection of self-harm indicators in digital text.

## Tech Stack
- Python
- HTML/CSS
- Flask 
- NLP Libraries (e.g., NLTK, spaCy, Scikit-learn)

## How to Run It
1. Install dependencies: `pip install -r requirements.txt`
2. Run the script: `python app.py`
